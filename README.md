# 校园选课与成绩记录管理系统

一个命令行课程项目，用于管理学生的选课和成绩记录，并比较不同数据结构的操作方式。程序以 `.c` / `.h` 文件组织；原 Dev-C++ 项目使用 `g++` 按 C++11 编译，因此构建时也需要使用 C++ 编译器。

## 功能

- 按“学号 + 课程编号”插入、查找、修改和删除记录；也可按学号、课程、学院、学期、成绩范围或日期批量删除。
- 按课程名称、学期、成绩范围、学院组合筛选；筛选结果可以按多个关键字排序并导出 CSV。
- 统计课程选课人数和成绩分布，分页浏览当前记录。
- 在双向链表、AVL 树、哈希表、动态数组之间切换存储结构；切换时迁移当前记录。
- 生成模拟记录，并对链表、AVL 树和哈希表做插入、查找、删除、修改的耗时对比。

## 构建与运行

需要支持 C++11 的 `g++`。Windows 上可以使用 MinGW-w64；项目也保留了 `student-grade-management-system.dev`，供 Dev-C++ 打开。

在项目根目录执行：

```powershell
mingw32-make
.\student-grade-management-system.exe
```

其他安装了 GNU Make 的环境可以执行 `make`，然后运行生成的 `student-grade-management-system.exe`。源码和 README 为 UTF-8；Windows 终端如果显示中文乱码，可先执行 `chcp 65001` 再运行程序。

首次运行时可选择菜单 `1` 生成模拟记录，然后用 `5` 查找、`6` 筛选、`7` 统计或 `11` 切换数据结构。选择 `0` 会把当前记录写入运行目录的 `records.csv`。下次运行选择 `2`，可以从该文件加载。筛选结果保存到运行目录的 `filtered_data/`。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `main.c` | 菜单、用户交互与功能入口 |
| `common.*` | 记录结构、日期和字符串等通用函数 |
| `data_store.*` | 统一存储接口、结构切换和批量操作 |
| `linked_list.*`、`avl_tree.*`、`hash_table.*`、`dynamic_array.*` | 四种记录存储实现 |
| `query.*` | 组合筛选、排序和统计 |
| `persistence.*` | CSV 读取、保存及筛选文件命名 |
| `data_generator.*` | 模拟记录生成 |
| `performance.*` | 三种结构的简单耗时对比 |
| `batch_delete.*` | 链表记录的日期批量删除辅助函数 |

每条记录包含学号、姓名、学院、课程编号、课程名、学分、学期、选课日期和成绩。程序以学号与课程编号的组合识别记录。

## 数据与限制

仓库不包含本地 `records.csv` 或 `filtered_data/`：这些文件可能包含学号、姓名和成绩。演示时请使用菜单 `1` 生成模拟数据，不要把真实学生数据提交到公开仓库。

这是课程练习程序。CSV 读写按固定字段顺序处理，交互输入和字段长度校验并不完善，暂不适合直接处理真实或不可信的成绩数据。性能对比使用程序内的简单计时，结果只适合观察本机运行情况，不能作为严谨的基准测试。
